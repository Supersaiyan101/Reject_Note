## 🔬 Keeping It Honest: The Optical rPPG Science

Hackathon judges are rightly skeptical of biometric claims in web applications. RejectNote does not use random numbers or scripted timers for its physiology engine. 

The application utilizes **Presage SmartSpectra optical photoplethysmography (rPPG)** to detect genuine autonomic cardiovascular responses through standard web cameras:

### 1. Sub Surface Dermal Hemoglobin Absorption
When the left ventricle of the heart contracts during systole, a pressure wave travels through the vascular tree to the facial capillary beds. Oxyhemoglobin absorbs green light strongly in the 520 nm to 570 nm spectral band. By isolating the facial region of interest (ROI) across successive video frames, SmartSpectra measures subtle luminance variations imperceptible to the naked eye.

### 2. Digital Signal Processing and Filtering
The raw chrominance difference signal is conditioned using a zero phase Butterworth bandpass filter tuned to physiological human cardiac limits (0.75 Hz to 3.0 Hz, corresponding to 45 BPM to 180 BPM). Pulse peaks are identified to calculate instantaneous heart rate.

### 3. Autonomic Nervous System Telemetry (HRV)
RejectNote computes **Heart Rate Variability (SDNN)** by evaluating the standard deviation of inter beat intervals across time. A sudden drop in SDNN under intense cross examination indicates acute sympathetic nervous activation (fight or flight stress response).

### 4. Respiratory Sinus Arrhythmia (RSA)
The respiratory waveform is derived from cyclic baseline modulations in the photoplethysmography signal caused by intrathoracic pressure variations during inhalation and exhalation.

### Optical Measurement Verification Table

| Measured Signal | Biological Origin | Processing Method | Primary Role in Roasting |
|---|---|---|---|
| **Pulse Wave (BPM)** | Left ventricular stroke volume | Green channel dermis absorption FFT | Triggers L's cardiac surge warnings |
| **Respiration Rate** | Diaphragm inhalation cycles | Respiratory Sinus Arrhythmia (RSA) | Detects hyperventilation under questioning |
| **HRV (SDNN ms)** | Autonomic vagal tone modulation | Inter beat interval variance | Measures genuine psychological panic |

## 🧠 L's Autonomous Psychological Deduction Engine

The core roaster operates via a zero key deterministic psychological deduction engine that evaluates candidate testimony and biometrics simultaneously:

* **Priority 1: Complete Silence (0 words spoken)**
  If a candidate stays silent when questioned under 64 cameras, L immediately deduces that guilt and fear have paralyzed their verbal defense. He refuses to prompt them and notes their biometric acceleration.
* **Priority 2: Terse Monosyllabic Deflections (1 to 3 words)**
  Short defensive answers such as *"no"*, *"idk"*, or *"whatever"* trigger L's psychological traps regarding evasiveness.
* **Priority 3: Autonomic Spike Correlation**
  If a candidate claims they scaled Kafka clusters while their pulse surges above 120 BPM and HRV drops below 20 ms, L highlights the physiological contradiction.
* **Priority 4: Ocular Avoidance**
  Gaze drift exceeding 25% away from the camera lens during technical defenses causes L to deduct credibility points.

## 🏁 Judge's 15 Second Test Drive (Local Setup)

The repository requires **zero API keys** and runs completely out of the box.

### Prerequisites
* [Node.js](https://nodejs.org/) v18.0 or higher
* Google Chrome, Microsoft Edge, or Brave with camera permissions enabled

### Installation and Execution

1. Clone the repository:
```bash
git clone https://github.com/Supersaiyan101/Reject_Note.git
cd Reject_Note
```

2. Install dependencies:
```bash
npm install
```

3. Launch the development server:
```bash
npm run dev
```
Open your browser to `http://localhost:5173/`.

### Evaluator Cheat Sheet (Testing Options)
* **Live Webcam Test**: Enter any name or upload a real PDF resume, allow camera access, sit still for 3 seconds of calibration, and answer L's questions through your microphone.
* **Instant Anime Demo Preset (Light Yagami)**: Click the Light Yagami preset button on the intake screen. This loads four iconic anime claims (Covert Potato Chip LCD rig, 40 Second Heart Attack SLA, Lind L. Tailor TV broadcast interception, and God of the New World distributed system) allowing judges to evaluate the full interrogation without needing to upload custom files.

## 🔒 Camera Consent, Privacy & Responsible Data Handling

Because RejectNote utilizes optical camera inputs for physiological feature extraction, responsible data handling is built into the architecture:

* **100% Client Side Execution**: All facial region of interest tracking, computer vision differencing, and rPPG signal filtering execute locally inside the browser using WebAssembly and WebGL.
* **Zero Video Transmission**: No webcam video frames, raw images, or audio recordings are ever transmitted over the network or saved to any server.
* **Zero Cloud Storage**: All candidate telemetry resides strictly in volatile browser memory and is discarded the moment the session ends or the tab is closed.
* **Explicit User Permission Gate**: The webcam stream is never activated automatically. The application requires explicit user interaction to start optical calibration.
* **Immediate Stream Release**: All media stream hardware tracks are promptly stopped when leaving the interrogation chamber.
