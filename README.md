## 🌟 Key Features

### 1. 🩸 Presage SmartSpectra Optical rPPG Biometrics
RejectNote integrates client-side contactless photoplethysmography (rPPG) that monitors your webcam feed to extract clinical autonomic indicators in real-time:
* **Arterial Pulse Coupling (BPM)**: Computes subtle micro-vascular color changes across facial regions of interest (ROI) caused by cardiac cycles.
* **Dual Waveform HUD**: Real-time arterial pulse waveform (emerald) synchronized with cyclic chest/diaphragm respiration wave (cyan).
* **Heart Rate Variability (SDNN in ms)**: Measures inter-beat intervals (RR-intervals) to assess vagal tone and acute psychological distress.
* **Autonomic Sympathetic Tone (%)**: Quantifies fight-or-flight cardiovascular activation during tough technical questioning.
* **Micro-Blink Estimation**: Measures blinks per minute as a stress index.
* **Ocular Gaze Alignment & Drift**: Detects when candidates avert their eyes or evade direct camera contact.

### 2. 🧠 Autonomous Zero-Key Forensic Deduction Engine
* **No API Keys Required Out of the Box**: Evaluators can run the entire experience immediately with zero configuration.
* **Deep Dynamic Reactivity**: L reacts directly to what you do:
  * **Silence / Empty Dialogue (0 words)**: L clocks your silence, deducing that guilt has paralyzed your verbal defense under 64 cameras.
  * **Terse Deflection (1–3 words)**: L dismantles monosyllabic answers (*"no"*, *"idk"*, *"whatever"*) as forensic evasion.
  * **Substantive Defenses**: L analyzes technical terminology, buzzwords (*"spearheaded"*, *"synergy"*), and domain claims (Frontend, Backend, Distributed Systems, Cloud).
* **Authentic Death Note Aesthetic**: Stacking sugar cubes, biting thumbnails, crouching on chairs, probability calculations (*"There is an 89.4% probability..."*), and razor-sharp psychological traps.

### 3. ⚡ Optional Gemini 2.0 Flash Neural AI Profiling
* Supports Google Gemini 2.0 Flash for unhinged, dynamic AI roasting. Simply supply an API key in the top navigation status bar.

### 4. 📄 Custom Resume PDF Parser & Preset Anime Lore
* **Upload Any Resume**: Drop your real-world PDF resume to have RejectNote extract your name, career title, education, and automatically flag high-risk technical landmines.

## 🚀 Quickstart: Running Locally

### Prerequisites
* [Node.js](https://nodejs.org/) v18.0 or higher
* Modern browser (Chrome, Edge, or Brave) with webcam and microphone permissions enabled

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Supersaiyan101/Reject_Note.git
   cd Reject_Note
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open your browser to `http://localhost:5173/`.

4. *(Optional) Configure Gemini API Key:*
   Click the **Gemini 2.0 Flash** status indicator in the top-right header to input your key, or set it in `.env`:
   ```bash
   VITE_GEMINI_API_KEY="your-google-ai-studio-api-key"
   ```
